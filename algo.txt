EXPERIMENT 1: LEXICAL ANALYZER

Step 1: Start.
Step 2: Define the list of C keywords and operators. Read the input program using getchar() until EOF.
Step 3: Define a function isKeyword() which returns 1 if the character buffer is a keyword, otherwise return 0.
Step 4: In main(), define the operator array operators[] = "+-*/%=".
Step 5: While the read character ch is not EOF:
    If ch is a space, tab or newline, skip it.
    If ch is an operator, print it as an Operator.
    If ch is a special character, print it as a Special Character.
    If ch is an alphabet, read characters into buffer until a non-alphanumeric character is found.
        Add the null character at the end of buffer.
        Push the extra character back using ungetc().
        If isKeyword(buffer) is true, print Keyword.
        Otherwise, print Identifier.
    If ch is a digit, read all consecutive digits into buffer.
        Add the null character at the end of buffer.
        Push the extra character back using ungetc().
        Print Constant.
Step 6: Stop.

Step 4: Define a recursive function find_closure():

EXPERIMENT 3: ε-NFA TO NFA CONVERSION

Step 1: Start.
Step 2: Declare transition, epsilon, closure and NFA arrays.
Step 3: Define findClosure():
    Set each state's closure to contain itself.
    Add all direct epsilon transitions.
    Repeat through all states to find indirect epsilon transitions.
Step 4: Read the number of states and input symbols.
Step 5: Read all normal and epsilon transitions.
Step 6: Read the initial state and final states.
Step 7: Call findClosure().
Step 8: For each state and input symbol:
    Find all states in its epsilon closure.
    Find their transitions for the input symbol.
    Find the epsilon closure of each destination state.
    Add these states to the new NFA transition table.
Step 9: Mark a state as final if its epsilon closure contains an original final state.
Step 10: Display the equivalent NFA transition table, initial state and final states.
Step 11: Stop.

EXPERIMENT 6: OPERATOR PRECEDENCE PARSER

Step 1: Start.
Step 2: Declare value and operator stacks.
Step 3: Initialize both stack pointers to -1.
Step 4: Define precedence():
    Return 1 for + and -.
    Return 2 for * and /.
    Return 0 for other operators.
Step 5: Define pushValue() and pushOperator() to insert elements into stacks.
Step 6: Define applyOperation():
    Pop two values and one operator.
    Perform the operation.
    Push the result into the value stack.
Step 7: Read the arithmetic expression.
Step 8: Scan the expression from left to right:
    If a space is found, skip it.
    If a number is found, extract the complete number and push it.
    If '(' is found, push it onto the operator stack.
    If ')' is found, perform operations until '(' is found.
    If an operator is found:
        Apply operators with higher or equal precedence.
        Push the current operator.
Step 9: Apply all remaining operators.
Step 10: Display the final result.
Step 11: Stop.


EXPERIMENT 7: FIRST AND FOLLOW

Step 1: Start.
Step 2: Read the number of productions and the grammar.
Step 3: Initialize FIRST and FOLLOW sets.
Step 4: Find FIRST of each non-terminal:
    If the symbol is a terminal, add it to FIRST.
    If the production contains epsilon, add epsilon.
    Otherwise, find FIRST of the symbols on the right-hand side.
Step 5: Find FOLLOW of each non-terminal:
    Add $ to FOLLOW of the start symbol.
    If a non-terminal is followed by a terminal, add that terminal.
    If followed by another non-terminal, add its FIRST excluding epsilon.
    If the remaining symbols can derive epsilon, add FOLLOW of the left-hand side.
Step 6: Repeat until no more symbols can be added.
Step 7: Display FIRST and FOLLOW sets.
Step 8: Stop.


EXPERIMENT 8: RECURSIVE DESCENT PARSER

Step 1: Start.
Step 2: Declare the input string and initialize the input pointer to 0.
Step 3: Define E():
    Call T().
    If successful, call E1().
Step 4: Define E1():
    If the current symbol is '+':
        Move the input pointer.
        Call T() and E1().
    Otherwise, accept epsilon.
Step 5: Define T():
    Call F().
    If successful, call T1().
Step 6: Define T1():
    If the current symbol is '*':
        Move the input pointer.
        Call F() and T1().
    Otherwise, accept epsilon.
Step 7: Define F():
    If the current symbol is 'i', move the pointer and return success.
    If the current symbol is '(':
        Move the pointer.
        Call E().
        Check for ')'.
        Move the pointer and return success.
    Otherwise, return failure.
Step 8: Read the input expression.
Step 9: Call E().
Step 10: If parsing succeeds and the entire input is consumed, print Input Accepted.
         Otherwise, print Input Rejected.
Step 11: Stop.


EXPERIMENT 9: SHIFT REDUCE PARSER

Step 1: Start.
Step 2: Declare stack and input arrays.
Step 3: Initialize stack pointer and input pointer.
Step 4: Define check() to perform reductions:
    If the stack contains i, reduce it to E.
    If the stack contains E*E, reduce it to E.
    If the stack contains E+E, reduce it to E.
    Repeat until no more reductions are possible.
Step 5: Read the input expression and append $.
Step 6: Initialize the stack with $.
Step 7: While the input is not completely processed:
    Shift the next input symbol onto the stack.
    Display the shift action.
    Call check() to perform reductions.
Step 8: If the stack contains $E and the input reaches $:
    Print Accepted.
    Otherwise, print Syntax Error.
Step 9: Stop.

EXPERIMENT 24: THREE ADDRESS CODE TO 8086 ASSEMBLY

Step 1: Start.
Step 2: Declare variables to store result, operands, operator and input code.
Step 3: Read the three-address code in the form:
        result = operand1 operator operand2.
Step 4: Extract result, operand1, operator and operand2 using sscanf().
Step 5: Generate MOV AX, operand1.
Step 6: Check the operator:
    If operator is '+':
        Generate ADD AX, operand2.
    If operator is '-':
        Generate SUB AX, operand2.
    If operator is '*':
        Generate MOV BX, operand2.
        Generate MUL BX.
    If operator is '/':
        Generate MOV BX, operand2.
        Generate MOV DX, 0.
        Generate DIV BX.
    Otherwise:
        Print Invalid operator.
Step 7: Generate MOV result, AX.
Step 8: Display the equivalent 8086 assembly instructions.
Step 9: Stop.
